# 예비 한글 글꼴

`NotoSansCJKkr-Regular.subset.otf`, `NotoSansCJKkr-Bold.subset.otf`는 Noto Sans CJK KR(SIL Open Font License 1.1, © Adobe / Google)에서
한글·라틴·기호·저장소 데이터에 쓰인 글자만 남긴 부분 글꼴이다. 글꼴 이름은 원본과 같다("Noto Sans CJK KR").

실행 환경에 apt로 `fonts-noto-cjk`를 설치하지 못할 때 `tools/setup_env.sh`가 이 파일을 `~/.local/share/fonts`에 복사한다.
