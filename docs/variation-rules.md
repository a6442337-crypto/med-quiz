# 변형문제 규칙

예약 작업(AUTOMATION.md 6~7단계)과 수동 작업이 같은 기준으로 변형문제를 만들도록 정리한 문서입니다.

## 1. 기존 내분비학 변형문제 분석 (39문항, 2026-11-16)

내분비학 퀴즈(옛 endo-quiz)의 변형 39문항을 원본 기출과 하나씩 비교했습니다.

| 항목 | 관찰 | 이 규칙에 반영한 것 |
|---|---|---|
| 개념 | 모두 원본 문항과 **같은 학습 목표**를 묻는다 (예: 25-42 문맥 순환 차단 → 줄기 절단 후 PRL 증가). | 변형은 원본의 핵심 개념을 바꾸지 않는다. |
| 선지 | 39문항 모두 원본과 선지가 하나도 겹치지 않는다. 오답은 같은 단원에서 자주 헷갈리는 개념으로 채웠다. | 대폭 변형은 선지를 새로 짜도 되지만, 오답은 "같은 단원에서 실제로 헷갈리는 것"이어야 한다. |
| 발문 | "옳은 것" ↔ "아닌 것", "진단" ↔ "치료" ↔ "다음 단계"를 바꿨다 (V11 '이상 소견' → '구성요소 개수와 진단', V20 '잔존효과 약물' → 'denosumab 중단 시 조치'). | 발문 방향·묻는 단계를 바꾸는 것은 소폭 변형의 기본 수단. |
| 증례 | 원본의 긴 증례를 한두 문장으로 **줄인** 경우가 많았다 (V05·V13·V36 등). | ✗ 고침: 증례형 원본의 변형은 원본 길이·형식의 증례를 유지한다(실제 시험처럼). |
| 수치 | 대사증후군·LDL 목표·부갑상선 수술 적응증처럼 **기준값 경계**를 넘나들게 수치를 바꿨다 (V22: 50세 미만 → 수술). | 수치를 바꿀 때는 기준값 바로 위/아래로 옮겨 정답이 바뀌게 만들 수 있다. 기준값은 강의 자료와 일치해야 한다. |
| 정답 위치 | **②에 27개(69%) 쏠림.** 원본 기출은 ①~⑤에 고르게 퍼져 있다. | ✗ 고침: 정답 위치를 고르게 (validate.py가 한 위치 40% 초과면 경고). 내분비 39문항은 재배열해 7/8/10/7/7. |
| 숫자 선지 | 수치 선지는 크기순으로 정렬 (V24). | 숫자·수치 선지는 오름차순 정렬 (정답 위치를 고르게 하는 규칙보다 우선). |
| 표기 | 근거에 "26 학습부 NN번"을 적었다. | 그대로 허용: `26 학습부 NN번(검안) · 강의명`. 학생 이름·전화번호는 넣지 않는다. |

또 내분비학에서는 교수님 경향을 반복(repeat)과 변형(vary) 두 가지로만 나눴습니다. 이 저장소는 이를 세 단계로 나눕니다(아래 §2).

## 2. 교수님별 변형 수준 판단

과목 문제집(최근 5개년)을 교수님별로 보고, **해마다 같은 개념의 문제가 어떻게 바뀌었는지** 비교합니다.

1. `tools/compare_years.py`가 1차 판정을 냅니다. 올해 문항마다 이전 연도의 같은 교수 문항 중 가장 비슷한 것 하나와 짝짓습니다.
   - **R (거의 그대로)**: 지문 유사도 > 0.85, 선지 80% 이상 같음, 정답 같음 (선지 순서만 바뀐 것 포함)
   - **m (소폭)**: 지문 유사도 ≥ 0.5 또는 선지 절반 이상 같음. 보기·수치·발문만 바뀐 것.
   - **M (대폭)**: 같은 개념이지만 지문·선지가 거의 다름. 다른 증례나 다른 형식(증례↔개념, 단일선택↔조합형).
   - 유사도 0.3 미만은 같은 개념이 아니라고 보고 비교에서 뺍니다.
2. 교수님별 판정:
   - R ≥ 60% → **repeat** (변형문제 만들지 않음)
   - M ≥ 40% → **major** (대폭 변형)
   - 그 밖 → **minor** (소폭 변형)
   - 비교 쌍 2개 미만(새 교수님, 1개년만 출제) → **minor** + "근거 부족" 표시
3. 작업자가 확인합니다. 짝지어진 문항 중 3쌍 이상을 직접 읽어 분류가 맞는지 보고, 복원 해설의 총평·문항 코멘트("작년과 동일", "선지만 바뀜", "기존 기출을 변형해서 내심")와 다르면 판정을 고칩니다. 고친 경우 `data/<slug>/chapters.json`의 해당 교수 항목에 `"mode"`와 `"why"`를 직접 적습니다.
4. 판단 결과와 비교한 문항 목록(올해 문항 ← 이전 문항, 분류)을 `reports/<slug>.md`에 남기고, `meta.json`의 `ch[].mode`, `ch[].why`에도 넣습니다(사이트 파트 버튼에 표시).

## 3. 변형문제 만들기

### 공통
- **repeat 교수님 파트에는 만들지 않습니다.** (validate.py가 막습니다)
- 원본 선택: 여러 해 출제된 개념(keys가 2개 이상) → 최근 연도 문항 순으로 고릅니다.
- 개수: minor·major 교수님마다 기출 수의 약 15~25%, 최소 1개, 최대 4개. 과목 전체로 20~45개 정도.
- 선지 5개, 서로 다르고, 정답은 하나만 분명해야 합니다. 정답·오답 판단 기준은 **2026년 강의 자료**입니다. 강의 자료가 아직 없으면 표준 교과서 지식으로 만들되 `ok:false`(미검증)로 둡니다.
- 정답 위치를 ①~⑤에 고르게 배분합니다(숫자 선지는 크기순이 우선).
- 해설에는 정답 이유와 **오답 선지마다 왜 틀렸는지**를 씁니다. 근거 표기는 강의 번호·강의명만 씁니다.
- `vn`(변형 내용)에 원본에서 무엇을 바꿨는지 한 줄로 적습니다. 사이트와 PDF에서 원본 번호와 함께 보입니다.
- 그림이 꼭 필요한 문항(영상 판독)은 그림 없이 풀 수 있게 소견을 글로 바꿔 씁니다.

### 소폭 변형 (minor): "보기·수치·발문만 바뀜" 수준
원본 증례의 틀(나이대·주소·검사 종류·질문 단계)을 유지하고, 아래 중 1~2가지만 바꿉니다.
1. **수치**: 기준값 경계를 넘나들게 바꿔 정답을 바꾸거나 유지합니다 (예: 증상 발생 1.5시간 → 5시간 ⇒ tPA 대상 아님, 혈전제거술).
2. **발문 방향**: 옳은 것 ↔ 옳지 않은 것, 진단 ↔ 치료 ↔ 원인 유전자.
3. **선지 2~3개 교체**: 같은 단원의 헷갈리는 개념으로 바꿉니다.
4. **짝 개념으로 교체**: 같은 형식 안에서 비교 대상만 바꿉니다 (Dandy-Walker 특징 고르기 → Chiari 1형 특징 고르기, 같은 보기 묶음).

### 대폭 변형 (major): "같은 개념을 다른 증례나 형식으로"
같은 학습 목표를 유지하면서 아래처럼 바꿉니다.
1. **개념형 → 증례형**: "Waller 변성 설명으로 옳은 것" → "정중신경 절단 2주 뒤 원위부 조직 소견".
2. **증례형 → 다른 증례**: 사지 실조(소뇌반구) → 체간 실조(소뇌 충부).
3. **형식 변경**: 단일 선택 → ㄱㄴㄷㄹ 조합형, 진술형 → 짝짓기.
4. 증례를 쓸 때는 원본과 비슷한 길이로, 나이·성별·경과·검사 수치를 갖춰 실제 시험 문항처럼 씁니다.

## 4. 데이터 형식 (variants.json)
```json
{"id":"V05","ch":2,"base":"25-91","lv":"minor","stem":"<div>…</div>","o":["…"],"a":2,
 "E":"정답·오답 이유","B":"관련 강의: 강의 04 뇌혈관질환 1","N":"2025년 91번 변형",
 "vn":"증상 발생 시간(1.5시간→5시간)과 혈관 폐색 정보를 바꾸고 오답 선지 2개 교체",
 "img":[],"v":true,"ok":false,"y":[]}
```
- `base`: 원본 기출 id (past.json에 있어야 함), `lv`: minor | major
- `ok`: 2026년 강의 자료로 정답을 확인했으면 true
